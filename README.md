# TikTok Batch Downloader – Releases

Repository công khai này chỉ dùng để phát hành các bản cài đặt chính thức của
TikTok Batch Downloader cho Windows. Mã nguồn ứng dụng không được lưu tại đây.

Tải phiên bản mới nhất tại trang
[Releases](https://github.com/QuocDuy1705/Tiktok-Auto/releases/latest).

Mỗi bản phát hành gồm:

- `TikTokBatchDownloader.exe`: bản portable cho Windows.
- `TikTokBatchDownloader.exe.sha256`: mã SHA-256 để tool tự xác minh cập nhật.
- `TikTokBatchDownloader_Windows_vX.Y.Z.zip`: gói đầy đủ gồm EXE, FFmpeg và FFplay.
